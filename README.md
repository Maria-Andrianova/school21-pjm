# IT Project Management

Учебные проекты по управлению IT-проектами из курса «IT Project Management» Школы 21 (Сбер).

## Планирование IT-проекта (Excel)

Папка `planning-it-project`.

Сравнительный анализ проектов по параметрам: цели, сроки, ресурсы, бюджет, результаты, роли, контроль, риски. Две таблицы:

- `Проект и процесс.xlsx` — промо-сайт и его поддержка (проект и процесс)
- `IT и не IT проект.xlsx` — мобильное приложение и Stand Up концерт за границей (IT и не IT проект)

## Методологии и инструменты управления проектами (Asana)

Папка `methodologies-asana`.

- `Жизненный цикл Авито.pdf` — жизненный цикл продукта на примере Avito
- `Agile и Waterfall.pdf` — принципы Agile с примерами, модель Waterfall по Ройсу
- `Как выбрать методологию.pdf` — памятка: Waterfall, Scrum, Kanban, гибридный подход
- `Доска Asana и календарь.pdf` — доска проекта в Asana и календарь рабочей недели менеджера проекта со Scrum-встречами

## Требования к сайту-гиду «Первая самостоятельная поездка» (Buildin.ai)

Папка `requirements-travel-guide`.

`Требования к сайту-гиду.pdf` — 8 функциональных требований с анализом аналогов, приоритетами и сценариями проверки, 16 рисков с мерами по каждому.

## Анализ продукта Duolingo и стратегия развития

Папка `product-analysis-duolingo`. Командный проект (4 человека). Вклад: стратегия развития (цель, шаги, метрики по сегментам с формулами), сборка финальной презентации.

- `Презентация_анализ_Duolingo.pptx` — финальная презентация по анализу продукта
- `Стратегия_развития_Duolingo.docx` — стратегия развития продукта

## User Story и бэклог для Duolingo (Miro, Asana)

Папка `user-story-duolingo`. Командный проект. Вклад: user stories, User Story Map в Miro, помощь с доской в Asana.

- `User_Story_Map_Miro.pdf` — User Story Map по релизам
- `Backlog_и_доска_Asana.pdf` — бэклог и доска задач в Asana
